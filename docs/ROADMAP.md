# Roadmap

ContextQuill is developed in public. Priorities are driven by safe usefulness, not feature count.

## Now

- Reliable Codex, ChatGPT Work, Claude Code, and local Claude Cowork packaging
- Public GitHub marketplace and downloadable plugin archives
- Human-reviewed text and single-image publishing
- Local-first signal, draft, schedule, audit, and performance storage
- Topic and format analysis with small-sample confidence labels

## Next

- Cross-platform secure credential storage beyond macOS Keychain
- Import wizard for official LinkedIn analytics exports
- Better image templates and accessible alt-text workflows
- PDF/document, carousel, and video publishing where official API access permits
- Portable backup and restore for the local content vault

## Later

- Optional hosted MCP service for cloud-only work agents
- Always-on hosted scheduling with explicit consent, retention, deletion, and audit controls
- A visual draft library and editorial calendar
- Team profiles, reviewers, and approval roles
- Compliant analytics synchronization if LinkedIn grants the required access

## Non-goals

- Scraping LinkedIn
- Reusing browser cookies or automating the website UI
- Publishing unreviewed AI-generated content
- Generating fake customer stories or synthetic personal experiences
- Optimizing for impressions at the expense of trust and qualified conversations
