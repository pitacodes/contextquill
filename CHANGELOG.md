# Changelog

All notable ContextQuill changes are documented here.

## 0.3.0 — 2026-09-03

### Added

- Public open-source packaging under the MIT License
- Installable marketplaces for Codex/ChatGPT Work and Claude Code/Cowork
- Direct-download plugin and local Codex marketplace archives
- Work-agent integration guide and automation playbook
- Public security policy, roadmap, issue templates, and automated release workflow
- Patched OAuth-service production dependencies before the public release

### Changed

- Reworked the project homepage for public onboarding and contributor discovery
- Clarified local scheduling, platform credential storage, and cloud-agent limitations
- Aligned plugin, MCP server, diagnostics, and package versions at 0.3.0

## 0.2.0 — 2026-07-21

- Added hosted one-click LinkedIn OAuth with installation-bound handoff
- Added secure local credentials, connect/disconnect tools, and identity verification
- Added official API publishing for text and single-image posts
- Added human review, scheduling, metrics, and exposure analysis

## 0.1.0 — 2026-07-20

- Initial local-first ContextQuill prototype
